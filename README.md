# Pedro Pascal Website

This website was created as part of a school project where we were tasked with building a site about a famous person, movie, painting, or another well-known subject. We were responsible for all aspects of design, development, and graphics. I chose Pedro Pascal as the focus.

## Project Details

The site was developed early in my education, so while it's fully functional, there are a few bugs that I haven’t fixed yet—and I might not get around to them. That said, there are no major issues, and the core functionality works as intended.

Feel free to explore the site as follows: https://ungkarl.github.io/PedroPascal/
